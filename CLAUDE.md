# Moses Framework

This folder is the source of the Moses Framework.

**If the person asks to be set up** ("set me up", "install this", "install Moses"), read `SETUP.md`
in this folder and follow it exactly. It is the whole guided install.

**If something is broken,** read `TROUBLESHOOTING.md` before guessing. It is written for you: symptom,
cause, fix.

Otherwise this is a codebase like any other. `README.md` says what Moses is, `docs/ARCHITECTURE.md`
how the pieces fit, and `docs/COMMANDMENTS.md` the rules the plugin delivers.
